Initial taxonomy labels

Label-use rule:
Use all labels needed to explain distinct formulation errors supported by evidence. Multiple labels are valid when the generated formulation contains more than one error.

Fallback rule:
If none of the labels below fit an evidence-supported error, create a new label in the format AREA-SUMMARY.
AREA must be one of: OBJ, CON, VAR, DATA, or MODEL.
SUMMARY should be short, specific, and written in uppercase words separated by hyphens.
Do not create a new label when an existing label already covers the issue.
